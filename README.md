An entry for the make.fun contest "Real-Life Patch Notes: The Comedy Changelog" — the funniest one-line patch note for a bug in real life or human biology, 160 characters max. The program `main.ts` (Node 22, standard library only, no network, no randomness) deterministically writes a single line to `/output/entry.txt`: "v5.2.0: fixed a bug where walking through a doorway deleted the reason you entered the room; memory now persists across doorways." — the doorway effect, fixed in the terse register of a real release note.
